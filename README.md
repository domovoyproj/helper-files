Публичное облачное файловое хранилище и CDN-бэкенд для экосистемы персонального PWA-помощника **[Helper](https://github.com/domovoyproj/helper-app)**.

Репозиторий функционирует как бессерверная платформа хранения медиафайлов: [Helper](https://github.com/domovoyproj/helper-app) загружает файлы через GitHub REST API, получает прямой URL к контенту через глобальный CDN GitHub (`raw.githubusercontent.com`) и автоматически сокращает ссылку с помощью TinyURL API для мгновенного обмена.

---

## 🏗 Архитектура и поток данных

```text
┌─────────────────┐       1. Base64 Upload (PUT /contents/uploads/{name})      ┌──────────────────────┐
│                 │ ─────────────────────────────────────────────────────────> │                      │
│   Helper PWA    │                                                            │  GitHub Repository   │
│ (Браузер/Клиент)│ <───────────────────────────────────────────────────────── │    helper-files      │
│                 │       2. Raw CDN URL (raw.githubusercontent.com)           │                      │
└─────────────────┘                                                            └──────────────────────┘
         │
         │ 3. POST запрос на сокращение ссылки
         v
┌─────────────────┐
│   TinyURL API   │ ────> 4. Короткая ссылка (tinyurl.com/...) ────> Буфер обмена / Карточка в Helper
└─────────────────┘
```

### Принцип работы

1. **Загрузка:** Пользователь прикрепляет файл в приложении Helper. Клиент кодирует файл в Base64 и выполняет `PUT`-запрос к GitHub REST API (`/repos/domovoyproj/helper-files/contents/uploads/{filename}`).
2. **CDN-ссылка:** По завершении коммита формируется прямая ссылка на сырой контент через `raw.githubusercontent.com`.
3. **Сокращение ссылки:** Helper обращается к API TinyURL и генерирует компактную ссылку.
4. **Удаление:** При удалении файла из истории Helper инициирует `DELETE`-коммит через GitHub API, освобождая место. Все транзакции прозрачно отражаются в истории коммитов репозитория.

## ⚡ Особенности

- 💸 **Zero-Cost инфраструктура:** Отсутствие необходимости арендовать и обслуживать выделенные S3/VPS-хранилища.
- 🚀 **Глобальный CDN:** Высокая скорость отдачи контента благодаря кэширующей сети `raw.githubusercontent.com`.
- 📜 **Полный аудит версий:** История коммитов репозитория служит точным логом всех операций загрузки и удаления файлов.
- 🔗 **Интеграция с TinyURL:** Автоматическое получение компактных ссылок для быстрой отправки в мессенджеры и соцсети.
- 🤖 **Полная автоматизация:** Все операции выполняются строго через API, ручное вмешательство в репозиторий не требуется.

## 📋 Технические параметры и ограничения

| Параметр | Значение | Примечание |
|---|---|---|
| **Максимальный размер файла** | ~15 МБ | Лимит GitHub Contents API на размер файла в теле одного коммита |
| **Целевой каталог** | `uploads/` | Все медиафайлы сохраняются в изолированной папке |
| **Формат наименований** | Оригинальное имя / хэш-префикс | Генерируется на стороне Helper во избежание коллизий |
| **Доступ к файлам** | Публичный (Read-only) | Любой пользователь по ссылке может просмотреть/скачать файл |
| **Необходимый скоуп токена** | `repo` (Personal Access Token) | Используется приложением Helper для совершения коммитов |

## 🔒 Безопасность и приватность

> [!WARNING]
> Данный репозиторий является **публичным**. Любой файл, загруженный в `uploads/`, становится общедоступным в сети Интернет.

- **Для чего предназначен `helper-files`:** Публичные изображения, документы для быстрого шаринга, видео и медиа-вложения.
- **Для чего НЕ предназначен `helper-files`:** Конфиденциальные данные, пароли, персональные токены и базы данных.
- **Резервные копии Helper:** Зашифрованная база данных приложения (`encrypted_helper_backup.json`) отправляется исключительно в **отдельный приватный репозиторий** с клиентским сквозным шифрованием (AES-256) и нулевым разглашением (Zero-Knowledge).

## ⚙️ Настройка связки в Helper

1. Откройте **Helper** → перейдите в раздел **Настройки**.
2. В блоке «Облачная синхронизация и файлы» укажите:
   - **GitHub Personal Access Token**: токен с правами `repo`.
   - **Репозиторий файлов**: `domovoyproj/helper-files`.
3. Сохраните настройки мастер-паролем. Теперь инструмент «Файлообменник» готов к работе.
